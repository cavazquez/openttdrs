# Issues de la matriz de mapas aleatorios

Este registro conserva issues reproducibles aun cuando la sesión local no
tenga un token válido para abrirlos automáticamente en GitHub. Cada issue
tiene un criterio verificable y apunta a la evidencia; no se declaran como
"paridad" las pruebas que sólo demuestran que el cargador acepta un `.sav`.

### RMAP-133 — Ejecutar el `TileLoop_Trees` tropical con el RNG global

### RMAP-137 — Resolver dinámicamente el límite automático de `GenerateTrees`

**Estado: cerrado (sub-issue acotado de RMAP-004/RMAP-009/RMAP-018).** La
primera divergencia de la frontera `trees` en temperate 2048²/seed

`construction.map_height_limit = 0` como el mínimo fijo 30; OpenTTD primero

34, el hook `tree-generation-trace` coincide en las **740.213/740.213**
llamadas admitidas, y la comparación raw de la frontera completa coincide en

### RMAP-139 — Configuraciones no predeterminadas de ríos y bordes de agua
